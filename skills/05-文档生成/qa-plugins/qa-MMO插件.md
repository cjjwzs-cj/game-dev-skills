# QA 测试文档插件 - MMO

## 适用场景
当策划案涉及以下内容时，在 QA 测试文档中追加本插件的测试场景：
- 拍卖行、交易行
- 世界聊天、组队
- 工会战
- 实时战斗同步

## 必加测试场景

### 一、拍卖行/交易行专项

| 测试场景 | 操作步骤 | 预期结果 | 风险等级 |
|----------|----------|----------|----------|
| 商品上架 | 上架道具 | 道具从背包扣除，上架成功 | 🔴 高 |
| 并发购买 | 多人同时购买同一商品 | 只有 1 人成功购买 | 🔴 高 |
| 价格范围 | 输入超低/超高价格 | 提示价格不在范围内 | 🟡 中 |
| 交易税 | 交易成功后检查税收 | 卖方收到扣除税后的金额 | 🔴 高 |
| 商品过期 | 上架商品超过时限 | 自动下架，邮件返还 | 🟡 中 |
| 交易记录 | 查看交易记录 | 记录完整，可筛选 | 🟢 低 |
| 竞拍出价 | 竞拍最后几秒出价 | 时间延长或按当前最高价成交 | 🔴 高 |

## 输出格式

本插件内容应追加到 QA 测试文档的对应章节，并在章节标题后标注 `[MMO]`。

### 输出要求
- 按风险等级排序：🔴 高 → 🟡 中 → 🟢 低
- 每个测试场景必须包含：操作步骤、预期结果、风险等级
- 章节标题必须包含 `[MMO]` 标签

### 无问题输出格式
如果策划案未包含MMO相关内容，输出：
```
⚠️ 策划案未包含MMO相关内容，未生成MMO专项测试场景
```

## 异常情况处理

| 异常情况 | 处理方式 |
|----------|----------|
| 策划案为空 | 输出错误："策划案内容为空，请提供有效的策划案内容" |
| 策划案格式异常 | 输出错误："策划案格式异常，请检查文件格式" |
| 不包含MMO内容 | 输出警告："策划案未包含MMO相关内容，未生成MMO专项测试场景" |
| 测试场景生成失败 | 输出错误："测试场景生成失败，请检查策划案内容或联系技术支持" |

## 边界情况处理

### 策划案内容不完整
- **情况**：策划案只包含部分MMO功能描述
- **处理**：基于现有内容生成测试场景，输出警告提示可能遗漏的测试场景

### 功能描述模糊
- **情况**：策划案中的功能描述过于模糊，无法准确判断测试场景
- **处理**：在测试场景中标注，建议明确具体实现细节以便生成更精确的测试场景
