# QA 测试文档插件 - 卡牌/RPG

## 适用场景
当策划案涉及以下内容时，在 QA 测试文档中追加本插件的测试场景：
- 抽卡、保底、招募
- 体力系统
- 阵容编队
- 副本关卡
- 装备强化、升星

## 必加测试场景

### 一、抽卡系统专项

| 测试场景 | 操作步骤 | 预期结果 | 风险等级 |
|----------|----------|----------|----------|
| 软保底验证 | 记录连续 N 次未出 SSR 后的概率变化 | 概率随次数递增，第 N 次达到峰值 | 🔴 高 |
| 硬保底验证 | 连续抽到保底次数，第 N+1 次必出 | 触发保底，获得 SSR | 🔴 高 |
| 十连抽概率 | 十连抽 1000 次，统计 SSR 数量 | 概率接近公示值 | 🟡 中 |
| 卡池切换 | 活动卡池切换瞬间抽卡 | 按新卡池规则，不返回旧卡池物品 | 🔴 高 |
| 保底跨卡池 | 在 A 卡池抽 N 次，切换到 B 卡池 | 保底计数是否共享（按策划案定义） | 🟡 中 |
| 并发抽卡 | 同一玩家同时发 10 次抽卡请求 | 保底计数正确，不重复扣款 | 🔴 高 |
| 抽卡记录 | 查看抽卡历史记录 | 记录完整，包含时间、卡牌、保底状态 | 🟢 低 |

### 二、体力系统专项

| 测试场景 | 操作步骤 | 预期结果 | 风险等级 |
|----------|----------|----------|----------|
| 体力上限 | 体力达到上限后继续领取 | 体力不变，超出部分不增加 | 🟡 中 |
| 自然回复 | 在线观察体力回复 | 每 X 分钟回复 Y 点 | 🟡 中 |
| 离线回复 | 下线 Y 分钟后再上线 | 按离线时间计算回复量 | 🟡 中 |
| 跨日重置 | 23:59:59 有剩余体力，00:00:01 查看 | 体力重置到上限（或按策划案） | 🔴 高 |
| 扣体力时机 | 进入副本时断网，重新登录 | 体力扣减与副本实际消耗一致 | 🔴 高 |
| 扫荡消耗 | 使用扫荡功能 | 正确扣除体力 + 扫荡券 | 🟡 中 |

### 三、阵容系统专项

| 测试场景 | 操作步骤 | 预期结果 | 风险等级 |
|----------|----------|----------|----------|
| 多阵容切换 | A 阵容和 B 阵容反复切换 | 数据独立，不相互覆盖 | 🟡 中 |
| 阵容保存 | 编辑阵容后不保存直接退出 | 修改不生效 | 🟢 低 |
| 阵容验证 | 上阵重复角色/超过数量上限 | 提示错误，不允许保存 | 🔴 高 |
| 战力计算 | 调整装备/角色后战力更新 | 战力实时刷新，与属性匹配 | 🟡 中 |
| 阵容分享 | 分享阵容生成图片 | 图片包含角色、装备、战力信息 | 🟢 低 |

### 四、副本/战斗专项

| 测试场景 | 操作步骤 | 预期结果 | 风险等级 |
|----------|----------|----------|----------|
| 体力不足 | 体力不足时进入副本 | 提示体力不足，无法进入 | 🟡 中 |
| 战斗失败 | 副本战斗失败 | 扣除体力或返还（按策划案） | 🔴 高 |
| 断线重连 | 战斗中断线重连 | 恢复到战斗中断状态 | 🔴 高 |
| 战斗结算 | 战斗胜利后获得奖励 | 奖励正确发放，体力正确扣除 | 🔴 高 |
| 扫荡功能 | 三星通关后扫荡 | 获得与手动战斗等量的奖励 | 🟡 中 |
| 首通奖励 | 首次通关副本 | 额外获得首通奖励 | 🟡 中 |

### 五、装备/养成专项

| 测试场景 | 操作步骤 | 预期结果 | 风险等级 |
|----------|----------|----------|----------|
| 强化材料不足 | 材料不足时点击强化 | 提示材料不足 | 🟡 中 |
| 强化成功率 | 强化有概率失败时的表现 | 按概率成功/失败，材料消耗正确 | 🔴 高 |
| 升星消耗 | 升星消耗对应数量材料 | 材料正确扣除，星级提升 | 🔴 高 |
| 装备分解 | 分解装备 | 获得对应分解材料 | 🟡 中 |
| 已装备分解 | 分解已装备的装备 | 提示卸下或自动卸下后再分解 | 🟡 中 |

## 输出格式

本插件内容应追加到 QA 测试文档的对应章节，并在章节标题后标注 `[卡牌RPG]`。
