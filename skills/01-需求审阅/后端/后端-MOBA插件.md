# MOBA 后端专项审阅插件

## 适用场景
策划案涉及以下内容时自动加载：
- 匹配系统（5v5、3v3）
- 对战房间
- 英雄、技能、天赋
- 野怪、兵线、防御塔
- 推塔、水晶
- 排位赛、赛季

## 后端必查清单

### 1. 匹配系统（MOBA 核心）

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 5v5 匹配 | 10 人凑齐的超时时间？放宽条件规则？ | 明确：每 X 秒放宽 Y 分段差 |
| 位置匹配 | 是否需要按分路匹配（上单、中单、打野、ADC、辅助）？ | 明确位置偏好匹配逻辑 |
| 补位机制 | 某个位置人数不足时，是否允许补位？补位是否有额外奖励？ | 明确补位规则和奖励 |
| 车队匹配 | 组队车队（2-5 人）如何匹配？段位分怎么计算？ | 按车队平均分或最高分匹配 |
| 匹配取消 | 匹配成功进入确认阶段，玩家未确认怎么办？ | 明确：超时踢出队列 + 惩罚 |
| 匹配保护 | 连败后是否匹配更强或更弱的队友？ | 明确是否存在 ELO 监狱机制 |

### 2. 对战房间/帧同步

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 同步方案 | 帧同步还是状态同步？ | MOBA 通常用帧同步，明确方案 |
| 帧率 | 每秒多少帧？客户端上报频率？ | 通常 15-30 fps |
| 延迟补偿 | 高延迟玩家如何补偿？ | 明确：预测 + 回滚 |
| 丢包处理 | 客户端丢包时的逻辑？ | 重传 + 关键帧快照 |
| 观战模式 | 观战是否有延迟（通常 2-3 分钟）？ | 明确延迟时间 |
| 断线重连 | 断线后多久内可重连？重连后如何恢复到当前帧？ | 保存关键帧快照 + 操作日志 |

### 3. 英雄与技能

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 英雄解锁 | 免费英雄、购买英雄的规则？ | 明确周免、永久、限时英雄 |
| 技能实现 | 技能逻辑在客户端还是服务端？ | 核心伤害计算必须服务端验证 |
| 技能 CD | 技能 CD 是否受减 CD 装备影响？ | 明确公式 |
| 技能命中判定 | 技能是否命中由谁判定？ | 服务端判定，防止外挂 |
| 天赋/符文 | 天赋配置在哪？战斗前还是战斗中？ | 战斗前锁定，战斗中不可变更 |

### 4. 战斗逻辑

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 伤害计算 | 普攻、技能伤害公式？暴击、穿透机制？ | 明确公式，服务端计算 |
| 野怪刷新 | 野怪刷新时间？BUFF 持续时间？ | 明确 |
| 兵线机制 | 小兵出生时间、刷新间隔、推进速度？ | 明确 |
| 防御塔 | 防御塔攻击优先级？脱战恢复时间？ | 明确 |
| 水晶/基地 | 基地无敌判定条件？被摧毁后胜负判定？ | 明确 |
| 经验/金币 | 击杀小兵、英雄、野怪的经验和金币分配规则？ | 明确分享公式 |

### 5. 结算系统

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 胜负判定 | 推掉水晶 vs 对方投降 vs 时间到推塔数？ | 明确所有胜负条件 |
| 评分系统 | MVP、SVP 的评分公式？ | 明确：KDA、输出、承伤、参团率等权重 |
| 段位分变化 | 胜利/失败后加减多少分？影响因子？ | 明确：段位差、表现分、连败/连胜系数 |
| 奖励发放 | 金币、经验、通行证进度的发放规则？ | 明确保底和上限 |
| 挂机/掉线惩罚 | 挂机玩家如何处理？队友是否会补偿？ | 明确：扣分 + 禁赛 + 队友不掉星 |
| 恶意行为检测 | 送人头、挂机、言语辱骂的检测和处罚？ | 明确检测规则和处罚码 |

### 6. 排位赛/赛季

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 段位体系 | 段位层级（青铜→白银→...→王者）和星级规则？ | 明确表格 |
| 晋级赛 | 晋级机制是星级还是晋级赛？晋级赛几局几胜？ | 明确 |
| 段位保护 | 刚晋级后几局内不掉段？ | 明确保护局数 |
| 赛季重置 | 新赛季段位如何重置？ | 明确公式（如：王者→铂金） |
| 赛季奖励 | 赛季结束奖励规则？按最高段位还是当前段位？ | 明确 |
| 巅峰赛 | 达到王者后是否有巅峰赛？独立分数？ | 明确规则 |

### 7. 反作弊（MOBA 重点）

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 全图视野 | 是否有全图视野外挂检测？ | 服务端不发送视野外单位信息 |
| 技能自瞄 | 技能自动瞄准的检测？ | 操作合法性校验（角度、距离） |
| 踢人挂 | 让对手掉线的攻击如何防护？ | 服务端权威 + 断线重连 |
| 脚本行为 | 自动走位、自动连招的检测？ | 行为分析 + 举报系统 |
| 演员检测 | 恶意送分、演员行为的检测？ | 异常数据检测 + 人工审核 |

### 8. 性能专项

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 房间容量 | 同时支持多少场对局？ | 预估峰值 |
| 帧同步负载 | 每局 10 人 × 30 fps × 操作数据量 | 压缩操作数据 |
| 战斗服扩容 | 战斗服是否支持扩容？ | 明确架构 |
| 观战负载 | 每局观战人数上限？ | 明确上限，推荐 10-50 人 |
| 战报存储 | 每局战报存储大小？保存多久？ | 按需归档，高频访问的热数据缓存 |

## 输出格式

### 标准输出格式

| 优先级 | 序号 | [MOBA]模块 | 问题描述 | 建议补充/修改 |
|--------|------|-----------|----------|----------------|
| P0 | 1 | 对战房间 | 帧同步方案未明确，断线重连恢复机制缺失 | 明确帧同步 + 关键帧快照 |
| P0 | 2 | 反作弊 | 技能命中依赖客户端判定，易被外挂 | 改为服务端全量判定 |
| P0 | 3 | 结算系统 | 挂机玩家无惩罚，队友无补偿 | 增加扣分 + 禁赛 + 队友不掉星 |
| P1 | 4 | 匹配系统 | 车队匹配规则未定义 | 明确车队如何匹配对手 |
| P1 | 5 | 排位赛 | 赛季重置规则缺失 | 明确新赛季段位继承公式 |

### 输出要求
- 按优先级排序：P0 → P1 → P2
- 每个问题必须包含：问题描述、建议修改
- 模块必须包含 `[MOBA]` 标签

- ✅ 英雄与技能

## 异常情况处理

| 异常情况 | 处理方式 |
|----------|----------|
| 策划案为空 | 输出错误："策划案内容为空，请提供有效的策划案内容" |
| 策划案格式异常 | 输出错误："策划案格式异常，请检查文件格式" |
| 不包含MOBA内容 | 输出警告："策划案未包含MOBA相关内容，检查结果可能不完整" |
| 审阅执行失败 | 输出错误："审阅执行失败，请检查策划案内容或联系技术支持" |

## 边界情况处理

### 策划案内容不完整
- **情况**：策划案只包含部分MOBA功能描述
- **处理**：基于现有内容审阅，输出警告提示可能遗漏的检查点

### 英雄规模不明确
- **情况**：策划案未明确英雄数量、技能规模
- **处理**：在问题描述中标注，建议明确英雄规模，以便评估性能和存储需求

### 帧同步方案不明确
- **情况**：策划案未明确帧同步的实现方案（帧同步/状态同步）
- **处理**：在问题描述中标注，建议明确帧同步方案，不同方案对性能和延迟有不同影响
