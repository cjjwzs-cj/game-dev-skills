# MMO 前端专项审阅插件

## 适用场景
策划案涉及以下内容时自动加载：
- 世界聊天、私聊
- 拍卖行、交易
- 组队、队伍
- 工会战
- 实时战斗同步
- 世界BOSS

## 前端必查清单

### 1. 世界聊天

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 聊天频道 | 支持哪些频道（世界、公会、队伍、私聊、系统）？ | 明确各频道 |
| 消息展示 | 消息列表的滚动方向？最新消息在上还是下？ | 通常是底部最新，自动滚动 |
| 表情/图片 | 是否支持表情、图片、语音？ | 明确支持范围 |
| 敏感词过滤 | 发送消息时客户端是否预过滤？ | 客户端预过滤+服务端最终过滤 |
| 消息CD | 发送消息是否有CD？CD期间UI提示？ | 按钮置灰+倒计时 |
| 未读提醒 | 后台时收到新消息是否在入口显示红点？ | 明确 |
| 屏蔽功能 | 是否支持屏蔽玩家？ | 明确 |
| 消息历史 | 下拉是否可加载历史消息？保留多少条？ | 明确，通常100-200条 |

### 2. 拍卖行/交易

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 商品列表 | 列表是否支持筛选（类型、等级、价格排序）？ | 明确筛选维度 |
| 商品详情 | 点击商品弹出的详情页包含哪些信息？ | 属性、价格、剩余时间 |
| 上架界面 | 上架时需要填写哪些信息？价格、数量？ | 明确 |
| 成交提示 | 自己上架的商品售出后是否有通知？ | 系统消息+邮件 |
| 竞拍 | 竞拍界面是否有倒计时？出价按钮？ | 明确 |
| 交易记录 | 是否有交易记录入口？ | 明确 |

### 3. 组队系统

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 队伍界面 | 队伍成员显示哪些信息？头像、职业、血量？ | 明确 |
| 队长功能 | 队长有哪些权限（踢人、转队长、开始匹配）？ | 明确 |
| 队员功能 | 队员有哪些功能（退出、准备、跟随）？ | 明确 |
| 准备状态 | 所有成员准备后才能开始？准备状态UI？ | 勾选图标 |
| 队伍招募 | 是否支持在世界频道招募？ | 明确 |
| 队伍查找 | 是否有队伍列表可供加入？ | 明确 |
| 跟随功能 | 是否支持跟随队长移动？ | 明确，通常MMO有 |

### 4. 实时战斗同步

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 同步方式 | 帧同步还是状态同步？前端需要做什么？ | 明确方案 |
| 延迟指示 | 是否有网络延迟显示（ping值）？ | 建议可视显示 |
| 断线重连 | 战斗中断线后如何重连？是否有重连入口？ | 自动重连+手动重连按钮 |
| 战斗UI | 技能栏、血条、小地图的布局？ | 明确布局 |
| 技能释放 | 技能释放方式？（点击、拖拽指向） | 明确 |
| 阵亡观战 | 玩家角色死亡后是否可以观战？ | 明确 |
| 战斗结束 | 结算界面是否可直接退出或返回大厅？ | 明确 |

### 5. 工会战

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 入口 | 工会战入口在工会界面还是独立入口？ | 明确 |
| 战况界面 | 实时战况显示哪些信息？双方分数、剩余时间？ | 明确 |
| 参战状态 | 玩家是否已参战的标识？ | 明确 |
| 排行榜 | 工会战伤害/贡献排行榜是否实时显示？ | 建议每N秒刷新 |
| 战报 | 战斗结束后是否有战报汇总？ | 明确 |
| 奖励展示 | 奖励预览界面？ | 明确 |

### 6. 世界BOSS

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 入口 | BOSS刷新时的入口提示？ | 全服广播+入口红点 |
| 场景 | BOSS场景是否多人同屏？同屏人数上限？ | 明确上限 |
| 伤害显示 | 玩家的伤害数字是否实时显示？ | 明确 |
| 排名 | 伤害排名是否实时更新？ | 建议每N秒刷新 |
| 奖励领取 | BOSS死亡后奖励如何领取？弹窗还是邮件？ | 明确 |

### 7. 性能专项

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 同屏人数 | 主城/战场最多同时显示多少人？ | 明确上限，超过则隐藏或简化 |
| 特效性能 | 多人同时放技能时引擎是否扛得住？ | 明确低端机降级方案 |
| UI预加载 | 常用界面是否预加载？ | 明确 |
| 内存优化 | 长时间在线是否有内存增长？ | 需要考虑资源释放策略 |

## 输出格式

### 标准输出格式

| 优先级 | 序号 | [MMO]模块 | 问题描述 | 建议补充/修改 |
|--------|------|----------|----------|----------------|
| P1 | 1 | 世界聊天 | 消息CD期间的UI反馈未定义 | 按钮置灰+倒计时数字 |
| P1 | 2 | 组队 | 队员跟随队长功能未定义 | 明确开关和跟随逻辑 |
| P1 | 3 | 实时战斗 | 断线重连入口未设计 | 战斗中掉线显示重连按钮 |
| P2 | 4 | 性能 | 同屏人数上限未定义 | 明确上限，超出只显示名字 |

### 输出要求
- 按优先级排序：P0 → P1 → P2
- 每个问题必须包含：问题描述、建议修改
- 模块必须包含 `[MMO]` 标签

### 无问题输出格式
如果未发现问题，输出：
```
✅ MMO 前端专项检查通过，未发现明显问题

检查模块：
- ✅ 世界聊天
- ✅ 拍卖行/交易
- ✅ 组队系统
- ✅ 实时战斗同步
- ✅ 工会战
- ✅ 世界BOSS
- ✅ 性能专项
```

## 异常情况处理

| 异常情况 | 处理方式 |
|----------|----------|
| 策划案为空 | 输出错误："策划案内容为空，请提供有效的策划案内容" |
| 策划案格式异常 | 输出错误："策划案格式异常，请检查文件格式" |
| 不包含MMO内容 | 输出警告："策划案未包含MMO相关内容，检查结果可能不完整" |
| 审阅执行失败 | 输出错误："审阅执行失败，请检查策划案内容或联系技术支持" |

## 边界情况处理

### 策划案内容不完整
- **情况**：策划案只包含部分MMO功能描述
- **处理**：基于现有内容审阅，输出警告提示可能遗漏的检查点

### 同屏人数规模不明确
- **情况**：策划案未明确同屏人数规模（主城、战场、世界BOSS）
- **处理**：在问题描述中标注，建议明确同屏人数规模，以便评估性能需求

### 网络同步方案不明确
- **情况**：策划案未明确实时战斗的同步方案（帧同步/状态同步）
- **处理**：在问题描述中标注，建议明确网络同步方案，不同方案对性能和延迟有不同影响
