# 卡牌/RPG 前端专项审阅插件

## 适用场景
策划案涉及以下内容时自动加载：
- 抽卡、招募
- 卡牌收集、养成
- 阵容编队
- 副本战斗
- 装备强化、升星

## 前端必查清单

### 1. 抽卡界面

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 抽卡动画 | 单抽/十连抽是否有动画？动画是否可跳过？ | 明确：可跳过，跳过时直接展示结果 |
| 结果展示 | 抽卡结果如何展示？紫色/金色特效？ | 明确稀有度的视觉表现 |
| 保底提示 | 距离保底还有多少次是否有显示？ | 建议显示保底计数器 |
| 十连抽 | 十连抽是一次性展示10张还是逐个展示？ | 明确交互形式 |
| 抽卡记录 | 是否有抽卡记录入口？记录保存多久？ | 明确，通常只显示最近20条 |

### 2. 卡牌/角色

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 卡牌图鉴 | 网格布局在大量卡片时是否有虚拟滚动？ | 超过50张需要虚拟列表 |
| 卡牌详情 | 点击卡片弹出的详情页包含哪些信息？ | 明确字段：属性、技能、故事 |
| 获得新卡 | 获得新卡时是否有特殊动画或红点？ | 明确：新卡特效 + 图鉴赏红点 |
| 卡牌筛选 | 是否支持按稀有度、属性、类型筛选？ | 明确筛选维度 |

### 3. 阵容编队

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 拖拽换位 | 拖拽换位是否流畅？是否有复位逻辑？ | 明确交互，支持拖拽和点击交换 |
| 多套阵容 | 支持几套阵容？切换时是否保存当前未确认的修改？ | 明确：3-5套，切换可保存草稿 |
| 阵容推荐 | 是否有系统推荐阵容功能？ | 明确是否提供 |
| 阵容分享 | 分享功能生成图片还是文字链接？ | 明确形式 |
| 战力显示 | 战力数值在哪里显示？装备/角色变更时实时刷新？ | 明确刷新时机 |

### 4. 副本/战斗

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 进入副本 | 进入副本前是否显示体力消耗和奖励预览？ | 明确 |
| 战斗入场 | 入场动画是否可跳过？ | 可跳过 |
| 战斗加速 | 是否有加速功能（1x/2x/3x）？自动战斗？ | 明确，自动战斗需玩家手动开启 |
| 战斗跳过 | 是否支持跳过战斗直接看结果？ | 明确：战力碾压时可跳过 |
| 战斗结算 | 结算界面显示哪些信息？获得奖励、经验、星级评价 | 明确 |
| 扫荡功能 | 扫荡是否消耗扫荡券？扫荡动画？ | 明确，扫荡可立即完成 |

### 5. 养成系统

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 强化/升级 | 强化时是否有动画反馈？材料不足时提示？ | 明确 |
| 升星/突破 | 升星动画效果？突破前后外观变化？ | 明确 |
| 一键升级 | 是否支持一键强化到最高级？ | 建议支持，需二次确认 |
| 资源显示 | 资源不足时点击是否跳转到获取途径？ | 明确跳转逻辑 |

### 6. 红点系统（前后端对齐关键点）

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 触发规则 | 红点触发规则由前端轮询还是后端推送？ | 明确，推荐后端推送 |
| 消除时机 | 红点消除后是否立即刷新？ | 立即刷新 |
| 多级红点 | 入口红点和内部红点如何联动？ | 层级传递，子页面消除后父级刷新 |
| 优先级 | 多个红点时按什么规则展示？ | 按优先级排序或全部显示 |

## 输出格式

### 标准输出格式

| 优先级 | 序号 | [卡牌RPG]模块 | 问题描述 | 建议补充/修改 |
|--------|------|--------------|----------|----------------|
| P1 | 1 | 抽卡 | 抽卡动画是否可跳过未明确 | 支持跳过，跳过后直接展示结果 |
| P1 | 2 | 阵容 | 多套阵容切换时长按拖拽未定义 | 明确：长按进入编辑模式 |
| P2 | 3 | 红点 | 红点消除后刷新规则未定义 | 立即刷新，不清除缓存 |

### 输出要求
- 按优先级排序：P0 → P1 → P2
- 每个问题必须包含：问题描述、建议修改
- 模块必须包含 `[卡牌RPG]` 标签

### 无问题输出格式
如果未发现问题，输出：
```
✅ 卡牌/RPG 前端专项检查通过，未发现明显问题

检查模块：
- ✅ 抽卡界面
- ✅ 卡牌/角色
- ✅ 阵容编队
- ✅ 副本/战斗
- ✅ 养成系统
- ✅ 红点系统
```

## 异常情况处理

| 异常情况 | 处理方式 |
|----------|----------|
| 策划案为空 | 输出错误："策划案内容为空，请提供有效的策划案内容" |
| 策划案格式异常 | 输出错误："策划案格式异常，请检查文件格式" |
| 不包含卡牌/RPG内容 | 输出警告："策划案未包含卡牌/RPG相关内容，检查结果可能不完整" |
| 审阅执行失败 | 输出错误："审阅执行失败，请检查策划案内容或联系技术支持" |

## 边界情况处理

### 策划案内容不完整
- **情况**：策划案只包含部分卡牌/RPG功能描述
- **处理**：基于现有内容审阅，输出警告提示可能遗漏的检查点

### 卡牌规模不明确
- **情况**：策划案未明确卡牌数量、稀有度分布
- **处理**：在问题描述中标注，建议明确卡牌规模，以便评估性能和存储需求

### 抽卡规则不明确
- **情况**：策划案未明确抽卡的具体规则（保底机制、概率分布）
- **处理**：在问题描述中标注，建议明确抽卡规则，不同规则对用户体验和商业化有不同影响
