# 棋牌/竞技 前端专项审阅插件

## 适用场景
策划案涉及以下内容时自动加载：
- 房间创建/加入
- 匹配等待
- 牌局/对局界面
- 段位/排行榜
- 结算界面

## 前端必查清单

### 1. 房间/匹配界面

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 房间创建 | 创建房间时可配置哪些参数？（局数、底分、是否允许观战） | 明确配置项 |
| 房间码 | 房间码的显示和输入方式？ | 数字/字母组合，可复制 |
| 匹配等待 | 匹配等待界面是否有倒计时？是否可取消？ | 明确：显示预计时间，允许取消 |
| 匹配成功 | 匹配成功后进入房间的过渡动画？ | 全屏加载 → 房间界面 |
| 房间内准备 | 玩家准备/取消准备的状态UI？ | 勾选图标或按钮变色 |
| 房主标识 | 房主是否有特殊标识（皇冠图标）？ | 明确 |
| 换位功能 | 是否支持座位换位？房主换位？ | 明确 |

### 2. 牌局/对局界面

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 牌面显示 | 自己的牌和其他玩家的牌显示方式？ | 自己：正面；对方：背面 |
| 倒计时 | 操作倒计时显示位置？样式？ | 明确：屏幕中央或操作区 |
| 操作按钮 | 出牌、过牌、托管、投降按钮布局？ | 明确 |
| 出牌动画 | 出牌是否有飞行动画？ | 明确 |
| 牌桌状态 | 当前轮到谁出牌是否有明显高亮？ | 明确 |
| 牌局记录 | 是否可查看本局出牌记录？ | 明确 |
| 设置功能 | 对局中是否可以调整声音、画质？ | 明确 |

### 3. 麻将特有（如适用）

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 手牌排序 | 手牌按什么规则排序？（花色、数值） | 明确 |
| 摸牌动画 | 摸牌时是否有动画？ | 有 |
| 碰杠胡 | 碰、杠、胡的操作按钮出现时机？ | 符合条件时显示 |
| 听牌提示 | 是否支持听牌提示功能？ | 明确，可设计开关 |
| 牌墙/牌河 | 打出的牌如何展示是否按顺序排列？ | 明确 |
| 剩余牌数 | 是否显示剩余牌张数？ | 通常显示 |

### 4. 扑克特有（如适用）

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 叫地主 | 叫地主按钮出现时机和倒计时？ | 明确 |
| 抢地主 | 抢地主倍数规则UI？ | 明确 |
| 倍数显示 | 当前倍数在何处显示？ | 明确 |
| 炸弹特效 | 炸弹是否有特效？ | 明确 |
| 牌型提示 | 选中牌是否提示可组成的牌型？ | 明确 |

### 5. 结算界面

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 结算内容 | 显示哪些信息？得分、段位变化、加减金币？ | 明确 |
| 动画效果 | 结算数字滚动的动画？ | 明确 |
| 段位变化 | 段位晋级/降级的动画效果？ | 明确 |
| 返回按钮 | 结算后「继续游戏」和「返回大厅」按钮？ | 明确 |
| 分享功能 | 是否支持分享战绩到社交平台？ | 明确 |

### 6. 段位/排行榜

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 段位图标 | 段位图标设计是否清晰易懂？ | 明确 |
| 段位进度 | 当前段位到下一段位的进度条？ | 明确 |
| 排行榜维度 | 支持哪些排行（全区、好友、亲密）？ | 明确 |
| 排名高亮 | 自己的排名是否高亮显示？ | 蓝色/金色高亮 |
| 加载更多 | 排行榜是否支持滚动加载更多？ | 明确，每次加载N条 |
| 段位奖励 | 段位奖励是否可预览？弹窗还是跳转？ | 明确 |

### 7. 断线重连（棋牌场景关键）

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 断线检测 | 断线时网络异常弹窗？ | 明确：Toast提示+重连弹窗 |
| 自动重连 | 是否自动重连？重连超时多久？ | 自动尝试3次，失败后手动 |
| 重连恢复 | 重连成功后牌局状态是否完全恢复？ | 手牌、牌桌状态、倒计时 |
| 托管状态 | 断线期间是否自动托管？提示？ | 明确：断线X秒后托管 |
| 重连失败 | 重连失败后的降级方案？ | 返回大厅+邮件补偿 |

### 8. 性能专项

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 动画流畅度 | 出牌、摸牌动画是否流畅（低端机）？ | 低端机可降低动画帧率 |
| 电池消耗 | 牌局场景是否持续消耗CPU？ | 后台时降低刷新率 |
| 内存占用 | 牌局资源（牌面图片）是否及时释放？ | 退出房间后释放 |

## 输出格式

### 标准输出格式

| 优先级 | 序号 | [棋牌]模块 | 问题描述 | 建议补充/修改 |
|--------|------|-----------|----------|----------------|
| P0 | 1 | 断线重连 | 断线后重连机制未定义 | 自动重连+手动重连按钮 |
| P1 | 2 | 牌局界面 | 手牌排序规则未明确 | 按花色+数值排序 |
| P1 | 3 | 结算 | 段位变化动画效果未定义 | 晋级/降级时弹窗+特效 |
| P2 | 4 | 性能 | 低端机动画降级方案未明确 | 设置中提供画质选项 |

### 输出要求
- 按优先级排序：P0 → P1 → P2
- 每个问题必须包含：问题描述、建议修改
- 模块必须包含 `[棋牌]` 标签

### 无问题输出格式
如果未发现问题，输出：
```
✅ 棋牌/竞技 前端专项检查通过，未发现明显问题

检查模块：
- ✅ 房间/匹配界面
- ✅ 牌局/对局界面
- ✅ 麻将特有（如适用）
- ✅ 扑克特有（如适用）
- ✅ 结算界面
- ✅ 段位/排行榜
- ✅ 断线重连（棋牌场景关键）
- ✅ 性能专项
```

## 异常情况处理

| 异常情况 | 处理方式 |
|----------|----------|
| 策划案为空 | 输出错误："策划案内容为空，请提供有效的策划案内容" |
| 策划案格式异常 | 输出错误："策划案格式异常，请检查文件格式" |
| 不包含棋牌竞技内容 | 输出警告："策划案未包含棋牌竞技相关内容，检查结果可能不完整" |
| 审阅执行失败 | 输出错误："审阅执行失败，请检查策划案内容或联系技术支持" |

## 边界情况处理

### 策划案内容不完整
- **情况**：策划案只包含部分棋牌竞技功能描述
- **处理**：基于现有内容审阅，输出警告提示可能遗漏的检查点

### 牌型规则不明确
- **情况**：策划案未明确具体的牌型规则（麻将/扑克的具体规则）
- **处理**：在问题描述中标注，建议明确牌型规则，不同规则对UI和逻辑有不同要求

### 房间规模不明确
- **情况**：策划案未明确房间规模（人数、局数）
- **处理**：在问题描述中标注，建议明确房间规模，以便评估性能和存储需求
