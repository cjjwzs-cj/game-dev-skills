# MOBA 前端专项审阅插件

## 适用场景
策划案涉及以下内容时自动加载：
- 英雄选择/禁用
- 对局界面
- 技能释放
- 小地图
- 装备购买
- 排位赛

## 前端必查清单

### 1. 匹配与英雄选择

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 匹配等待 | 匹配等待界面显示什么？预估时间、已等待时间？ | 明确 |
| 匹配成功 | 匹配成功后进入英雄选择界面的转场？ | 明确 |
| 英雄选择 | 英雄网格展示？是否显示熟练度、皮肤？ | 明确 |
| 禁用阶段 | 是否有禁用英雄阶段？禁用顺序？ | 明确（排位赛常见） |
| 选英雄顺序 | 按什么顺序选英雄？预选功能？ | 明确 |
| 交换英雄 | 是否支持队友之间交换英雄？ | 明确 |
| 天赋/符文 | 选择英雄时是否可调整天赋/召唤师技能？ | 明确 |
| 准备确认 | 所有玩家选完后是否有准备确认倒计时？ | 明确 |
| 阵容提示 | 阵容不合理时是否有提示（缺AP/缺肉）？ | 明确 |

### 2. 加载界面

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 加载进度 | 显示哪些内容？敌方玩家加载进度？ | 通常只显示自己和队友 |
| 英雄皮肤 | 是否展示英雄皮肤原画？ | 明确 |
| 加载速度 | 加载慢的玩家如何处理？ | 进入后等待或给出提示 |
| 队伍对比 | 是否显示双方阵容和召唤师技能对比？ | 明确 |

### 3. 对局界面 - 核心HUD

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 小地图 | 小地图位置？大小？是否可缩放？ | 明确 |
| 英雄信息 | 血条、蓝条、等级、经济在哪里显示？ | 明确 |
| 技能栏 | 4个技能键 + 召唤师技能键 + 回城键布局？ | 明确 |
| 普攻键 | A键还是摇杆自动攻击？ | 明确 |
| 装备栏 | 装备栏位置？点击可购买装备？ | 明确 |
| 战绩面板 | 点击何时显示战绩面板？ | 明确（长按或点击按钮） |
| 信号系统 | 信号按钮位置？（进攻、撤退、集合） | 明确 |
| 聊天入口 | 局内聊天入口？ | 明确 |

### 4. 技能释放

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 指向性技能 | 指向性技能的释放方式？ | 点击头像或拖动到目标 |
| 非指向性技能 | 非指向性技能的指示器样式？ | 明确（扇形/直线/圆形） |
| 智能施法 | 是否支持智能施法？ | 明确 |
| 技能取消 | 技能释放中如何取消？ | 拖动到取消区域 |
| 技能CD显示 | CD期间的视觉反馈？ | 黑色遮罩+倒计时数字 |
| 技能升级 | 升级技能的方式？ | 明确（升级按钮或自动） |

### 5. 战斗交互

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 平A机制 | 平A自动锁定最近的敌人？还是可切换目标？ | 明确 |
| 攻击优先级 | 小兵/英雄/防御塔的默认攻击优先级？ | 明确 |
| 拖拽视野 | 是否支持拖拽屏幕看远处？ | 明确 |
| 镜头跟随 | 镜头是锁定英雄还是可拖拽？ | 明确 |
| 补刀/推塔键 | 是否区分补刀键和推塔键？ | 明确 |
| 英雄控制 | 移动摇杆位置？固定还是跟随手指？ | 明确 |

### 6. 小地图

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 图标显示 | 友方/敌方英雄图标样式？防御塔、野怪图标？ | 明确 |
| 点击跳转 | 点击小地图是否跳转到对应位置？ | 明确 |
| 信号发送 | 在小地图上发信号的交互？ | 长按或点击信号按钮后点小地图 |
| 视野迷雾 | 未探索区域是否显示迷雾？ | 明确 |
| 战争迷雾 | 没有视野的区域显示什么？ | 灰色/黑色 |
| 队友头像 | 小地图边缘是否显示队友头像？ | 明确 |

### 7. 装备商店

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 打开方式 | 如何打开商店？是否可在局内打开？ | 明确（按钮） |
| 推荐装备 | 是否有系统推荐出装？ | 明确 |
| 装备分类 | 装备按什么分类？（攻击、法术、防御、移动） | 明确 |
| 预购功能 | 是否支持预购装备？ | 明确 |
| 快捷购买 | 是否有一键购买推荐装备的按钮？ | 明确 |
| 出售装备 | 装备出售的价格返还比例？ | 明确（通常100%原价） |

| 印记/荣誉 | 击杀、连杀、助攻是否有特殊播报？ | 明确 |

| 数据展示 | 展示哪些个人数据？KDA、输出、承伤、参团率？ | 明确 |

### 12. 性能专项

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 帧率 | 目标帧率？低端机目标帧率？ | 明确：60fps目标，30fps底线 |
| 团战性能 | 5v5团战特效多时是否会掉帧？ | 低端机简化特效 |
| 高帧率模式 | 是否支持120fps高帧率模式？ | 明确 |
| 发热控制 | 长时间对局是否发热降频？ | 智能降帧策略 |
| 资源加载 | 英雄皮肤资源是否按需加载？ | 明确（预加载或对局内加载） |
