# SLG 前端专项审阅插件

## 适用场景
策划案涉及以下内容时自动加载：
- 大地图、行军
- 攻打、占领
- 联盟、集结
- 城池、资源田
- 攻城战

## 前端必查清单

### 1. 大地图渲染

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 地图拖动 | 拖动是否流畅？是否有惯性效果？ | 明确，使用虚拟列表/瓦片复用 |
| 地图缩放 | 缩放级别范围？缩放中心点？ | 明确最小/最大缩放级别 |
| 瓦片加载 | 大地图瓦片加载策略？预加载？ | 预加载当前视口周围的瓦片 |
| 地块类型 | 不同地块的视觉区分（草地/山脉/河流/资源田） | 明确图例 |
| 部队显示 | 地图上的部队显示方式？头像还是图标？ | 明确样式 |
| 建筑显示 | 玩家建筑（城池、堡垒、哨塔）在地图上如何显示？ | 明确层级和缩放显示规则 |

### 2. 行军交互

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 选择目标 | 点击地块后选择行军、攻打还是其他操作？ | 明确操作菜单 |
| 行军范围显示 | 行军距离是否有限制？是否高亮可到达范围？ | 高亮可到达格子 |
| 行军线 | 行军过程是否有行军线动画？多支部队时如何区分？ | 不同颜色或虚线样式 |
| 行军确认 | 出发前是否需要二次确认？显示耗时和兵力？ | 确认弹窗 |
| 行军取消 | 行军途中是否可以取消？取消UI在哪里？ | 部队详情页取消按钮 |
| 多支部队 | 同一格子有多支部队时如何展示？ | 堆叠显示数量，点击展开 |

### 3. 战斗表现

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 战斗入场 | 点击攻打后是否进入战斗场景？还是大地图跳字结算？ | SLG常见大地图结算，明确形式 |
| 战报展示 | 战报页面包含哪些信息？是否有「查看战场」功能？ | 明确 |
| 战报跳转 | 点击战报地点是否能跳转到大地图位置？ | 支持跳转 |
| 集结界面 | 集结发起时，联盟成员的集合界面？ | 明确UI和倒计时 |

### 4. 联盟/社交

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 联盟聊天 | 聊天频道是否区分联盟、世界、私聊？ | 明确各频道 |
| 新消息提醒 | 未读消息红点？是否需要声音提醒？ | 明确 |
| 联盟帮助 | 一键帮助的UI？是否支持批量点击？ | 支持全部帮助 |
| 联盟地图 | 联盟成员的城堡位置是否在大地图上标记？ | 用联盟图标标记 |
| 联盟通知 | 联盟战开启、成员加入等通知形式？ | 系统消息 + 可能推送 |

### 5. 城池/内政

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 城池建设 | 建筑升级/建造是否有动画？队列显示？ | 明确 |
| 资源显示 | 主界面资源条显示哪些？是否可点击跳转？ | 明确可跳转资源详情 |
| 加速功能 | 是否支持加速道具？使用UI？ | 明确 |
| 一键收取 | 资源建筑是否支持一键收取？ | 建议支持 |

### 6. 多分辨率/性能适配

| 检查点 | 问题 | 建议 |
|--------|------|------|
| 大地图性能 | 移动端大地图拖动是否流畅（低端机）？ | 提供画质降级开关 |
| 同屏人数 | 大地图同屏显示多少部队/建筑不影响性能？ | 明确上限，超过则简化显示 |
| 分辨率适配 | 刘海屏、异形屏是否适配？ | 明确安全区适配方案 |
| 低端机降级 | 低端机是否可关闭特效、降低同屏数量？ | 明确设置选项 |

## 输出格式

| 优先级 | 序号 | [SLG]模块 | 问题描述 | 建议补充/修改 |
|--------|------|----------|----------|----------------|
| P1 | 1 | 大地图 | 地图缩放级别范围未明确 | 最小显示行政区划，最大显示地块细节 |
| P1 | 2 | 行军 | 多支部队重叠显示方式未定义 | 堆叠显示数量，点击展开列表 |
| P2 | 3 | 性能 | 低端机大地图降级方案未明确 | 增加画质设置：低/中/高 |
