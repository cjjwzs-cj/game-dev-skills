# Game Development Skills

**Name:** 🎮 Game Development Skills

**Description:** Complete AI skill library for game development - 47 production-ready skills with intelligent error handling and standardized output formats. Supports planning review, design validation, tech stack adaptation, code quality, documentation, and testing strategies for various game types (RPG, FPS, MOBA, SLG, MMO, Chess, Casual) and tech stacks (Unity, Unreal, Cocos, Go, C++, Java, Python, Node.js).

**License:** MIT

## Features

- 🎯 **47 Production-Ready Skills** covering all aspects of game development
- 🛡️ **Comprehensive Error Handling** with complete exception handling tables
- 📋 **Standardized Output Formats** with priority-based sorting (P0/P1/P2)
- 🎮 **Multi-Game Type Support** for RPG, FPS, MOBA, SLG, MMO, Chess, Casual games
- ⚙️ **Multi-Tech Stack Support** for Unity, Unreal, Cocos, Go, C++, Java, Python, Node.js
- 📊 **Config Table Detection** with intelligent analysis for Excel, CSV, JSON, XML, YAML
- 🧪 **Built-in Validation** and testing tools

## Installation

```bash
npx skills add https://github.com/cjjwzs-cj/game-dev-skills
```

## Usage

After installation, skills are available in your AI tool's skills directory. Use them for:

- 📝 **Planning Review**: Backend and frontend planning document reviews
- 🔍 **Design Validation**: API, database, security, network, performance reviews
- 🔧 **Tech Stack Adaptation**: Language and engine-specific guidance
- ✅ **Code Quality**: Code review and unit test generation
- 📚 **Documentation**: API and QA test documentation generation
- 🧪 **Testing Strategy**: Automated testing and testing frameworks
